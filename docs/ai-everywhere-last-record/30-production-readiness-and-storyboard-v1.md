## Замечания о production readiness

1. Storyboard нужно собрать через QwenDirector по этим anchors, с отдельными image jobs и refs на каждый смысл/масштаб; job выше — первый кадр для квалификации профиля, не разрешение штамповать весь пакет тем же workflow.
2. Для каждой сцены после storyboard lock нужна final shot bible: отдельные stable IDs, 24fps in/out, source handles, action endpoints, camera start/end, focus plane/DoF reason, exposure, axis, cut type, trigger evidence/confidence, QC and fallback. Этот предварительный список ещё не EDL.
3. H3 production: один доминирующий physical action chain на 5–8 s generated source; timeline trims обычно 0.4–4 s по конкретному движению. Каждую смену крупности/оси готовить отдельным job. Crowd — отдельные малые группы; не рассчитывать на массовую multi-person consistency.
4. Старые QD scene prompts/jobs, `10`–`19`, отвергнутые ControlNet A/B и старый `17-production-shot-map-v1` не являются источником текущих actions. Они сохраняются только в provenance; не отбирать их в EDL без нового пользовательского выбора.
5. Конечный клип не готов: нет storyboard output, новых H3 scene takes, полного shot review, согласованного location layout, финального EDL/рендера. После каждого реального шага записать hashes/AssetVersion IDs, QC и rejected takes.

# Продуктовый brief

## Задача

Режиссёр должен пройти путь «замысел → сценарий → сцены → шоты → варианты → утверждённые ассеты → экспорт» внутри локальной студии. Оркестратор помогает планировать и выполнять работу, но утверждение дорогих запусков и финального варианта остаётся управляемым пользователем.

Основной пользователь — владелец домашней лаборатории и автор видео. Первый проект — короткая сцена из нескольких шотов, в которой один шот можно перегенерировать другим адаптером без потери истории.

## Сущности

| Сущность | Назначение |
|---|---|
| Project → Scene → Shot | Иерархия, порядок, длительность, режиссёрские заметки |
| ScriptRevision / ShotPlanRevision | Неизменяемые версии сценария и плана |
| PromptRevision | Текст, negative prompt, параметры, автор, parent revision |
| Asset / AssetVersion | Логический ассет и неизменяемые байты с SHA-256 |
| ReferenceBinding | Роль референса, привязка к шоту и конкретной версии ассета |
| GenerationSpec | Модельно-независимое намерение, modality, ограничения и ссылки |
| Job / Attempt | Логическая работа и конкретная попытка исполнения |
| Approval | Кто и когда утвердил hash входов и execution plan |
| Node / CapabilitySnapshot | Узел, устройства и актуальные возможности |
| Provenance / AuditEvent | Происхождение результата и история действий |

Промпт переносим как текст и намерение; параметры конкретной модели находятся в namespaced adapter options. Перенос между моделями не обещает визуального равенства.

## MVP

Создать проект, сцену и шот; сохранить версии промпта и референсы; собрать план; утвердить запуск; выполнить mock и затем один локальный ComfyUI workflow; увидеть статус/ошибку; отменить; сравнить варианты; утвердить результат; экспортировать manifest и ассеты. Минимальная библиотека загрузки и просмотра входит в MVP, расширенные поиск и превиз — позже.

Утверждение запуска и утверждение результата — разные действия. Новый hash плана требует нового утверждения. Дорогие действия и внешняя передача требуют отдельного разрешения; автоповторы ограничены политикой утверждённого плана.

## Не входит в первый выпуск

Облачный marketplace, обучение моделей, полноценный видеомонтаж, автоматическое управление Proxmox, неограниченная автономная генерация, production HA и полноценный 3D-редактор. Qwen runtime в первом срезе — локальный llama.cpp; ComfyUI подключается к PVE `pct 103` как отдельный adapter.

## Проверка ценности

Контрольная сцена проходит весь путь после рестарта API. Пользователь видит входы, исполнителя, затраты времени и причину ошибки каждого варианта. Замена адаптера создаёт новый вариант того же шота. Работа без интернета возможна при заранее подготовленных локальных зависимостях и моделях.

## Открытые вопросы

Нужны фактические VRAM вариантов 4060 Ti, топология сети/дисков и размещение 5090, версии и endpoints локальных серверов, первый workflow, целевые форматы видео, объём библиотеки и политика retention. Репозиторий Director Studio и его лицензия не предоставлены. Ни один из этих фактов пока не проверен.

# Архив workflow прежнего AI-Everywhere

Эти два ComfyUI API graph содержат prompts и references для прежней версии клипа. Они перемещены из активного каталога, чтобы случайно не использовать их для новой концепции и аудиотрека. JSON сохранён без изменений для воспроизводимости старой работы; текущие QwenDirector workflow profiles и ComfyUI user data не менялись.
